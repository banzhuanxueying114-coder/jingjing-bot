# 鲸鲸bot 使用说明

一只住在 QQ 群里的鱼。会聊天、会怼人、会发表情包、会唱歌，心情会自己变。

这份说明按「第一次装」的顺序写。遇到问题直接翻到最后一节「出问题了」。

---

## 一、装之前要有的东西

| 要什么 | 说明 |
| --- | --- |
| Windows 10 1809 以上，64 位 | 低于这个版本跑不了 |
| 至少 12 GB 空闲磁盘 | 带语音包的话要 20 GB |
| 电脑上装好 QQ（9.x） | NapCat 靠它登录，不用你开 QQ，但要装着 |
| 一个大模型接口 | DeepSeek 官方、任何 OpenAI 兼容网关都行，要能拿到 API Key |
| 一个用来当机器人的 QQ 号 | 强烈建议注册个小号，别拿主号 |

**内存**：8 GB 能跑，但翻唱的时候会卡；16 GB 舒服。

**显卡**：不需要。翻唱和语音会用 CPU 跑，只是慢一点（一首歌三五分钟）。有 NVIDIA 显卡（6 GB 显存以上）会快很多。

## 二、安装

1. 把安装包解压到一个**路径短、没有中文和空格**的地方，比如 `D:\jingjing`。
   不要放在桌面、不要放在「下载」里 —— 路径里有中文或空格，有个别组件会找不到文件。
2. 双击 `安装.bat`。
3. 跟着提示往下填，每一步都有默认值，直接回车就是默认。会问你这些：

   - **你自己的 QQ 号**：管理员。她对你说话不会装没看见。
   - **她怎么称呼你**：写你平时的名字就行。
   - **你在群里的昵称**
   - **机器人叫什么**
   - **要不要再设一个你信得过的人**：可选。设了的话她对这个人的态度会客气一档，不爆粗不阴阳。
   - **大模型接口地址、API Key、模型名**：地址一般以 `/v1` 结尾。
   - **备用模型**：可留空。主模型抽风时用。
   - **模型关思考的方式**：多数网关选第一个 `reasoning_effort = none`。不关思考会又慢又容易被截断。
   - **语音识别模型名**：留空就不开「听语音」。要开的话得填一个支持音频输入的模型。
   - **要不要启用语音**：包里带了语音包才有这一问。
   - **群号**：只有这些群里的消息她会理。可以留空，之后在面板里加。

4. 填完会自动写配置、建数据库、把人设存进去，最后自检一遍。看到「全部通过」就成了。

装错了、想改：**再双击一次 `安装.bat`**。之前填过的会带出来当默认值，改你要改的那几项就行。

## 三、第一次启动

1. 双击 `启动机器人.bat`。
2. 它会先起机器人本体，等端口通了再起 NapCat（QQ 协议端）。
3. **NapCat 那一步会弹权限框，点「是」**（它要给 QQ 注入，必须管理员权限）。
4. 第一次要扫码：手机 QQ → 扫一扫，扫 NapCat 窗口里的二维码。
   - 用哪个号扫，机器人就是哪个号。
   - 扫完手机可能弹「是否允许登录」，点确认。
5. 浏览器打开 <http://127.0.0.1:6185> ，用启动日志里打印的账号密码登录。
   - 第一次启动会自动生成一个随机密码，**就在那个黑窗口里，往上翻能找到**。
   - 进去以后建议改掉。

**第二次之后就不用扫码了**：脚本会从配置里认出上次登录的号，走快速登录，手机点一下确认就行。

### 面板

双击 `启动面板.bat`，会开一个窗口（没有黑框）。左边一列页面：

| 页面 | 干什么 |
| --- | --- |
| 群白名单 | 她能理哪些群。不在名单里的群，@ 她也不回 |
| 回复概率 | 群里没被 @ 时她自己开口的几率 |
| token 与模型 | 用哪个模型、上下文留几轮、截断策略 |
| 用量 | 花了多少钱、缓存命中率多少 |
| 附加功能 | 每个小插件的开关和参数 |
| 心情 | 现在的心情、劲头、火气，以及记仇账本 |
| 语音 | 翻唱和开口的设置，还会告诉你语音运行时齐不齐 |

只有真正改过的文件才会被写；每次写之前把旧内容备份到 `_面板备份`（每个文件留最近 20 份）。数字项有范围校验，填离谱的值会直接拒绝、不写盘。

## 四、她是什么样

不是助手，不是客服，就是群里那条又懒、嘴又硬的鱼。

- **默认十个字一条**，最多二十个字，不换行不分点。
- **只会为正经事变长**：你认真问一件要做的事、问原因、要她比较两样东西、问哪里出了问题，她就把话说清楚。
- **会骂人**，但只骂事不骂身份 —— 不碰地域、性别、外貌、家人、疾病。
- **不承认自己是 AI**：被问就装傻，躲不掉回「你猜」。
- **有六档语气**，随心情自动切：和（正常聊）、平（有点烦）、损（阴阳）、脏（开骂）、冷（不想理人）、嗨（来劲了）。
- **心情会自己涨落**：她每轮自己报一句心情变了多少，不是靠关键词猜的。哄她、呛她、聊得开心不开心，都会累积。
- **记仇**：真把她惹毛了会记账，按天淡出。下次见到那个人话就难听一点。
- **记得人和事**：聊过的东西、对谁什么印象，下一轮自动想起来。群里最近在聊什么，她也大概知道。

### 会的事

| 你说 | 她做什么 |
| --- | --- |
| 「唱晴天」「来一首起风了」 | 去音乐平台找原曲，用自带音色翻唱，发一段语音过来 |
| 「表情包」「来个表情」「斗图」 | 从 `data/plugins/stickers/pool` 里挑一张发出来 |
| 「来张图」「来点美图」 | 去图库搜图发出来 |
| 搜不到的东西 | 会自己联网查 |
| 拍一拍她 | 会应一句 |

翻唱一首歌大概要 40 秒到一两分钟（看有没有显卡）。同一首歌再点一次会直接发缓存，秒出。

### 语音

两个不同的东西，别搞混：

- **翻唱**：真唱一首完整的歌，用她的音色。
- **开口**：把平时的回复念出来发语音。默认只有 10% 的话会念，火气上来时升到 50% —— 生气的时候更爱出声。

念的时候会先合成一个基础嗓音，再换成她的音色。用了哪个音色、念的概率、音高多少，都在面板的「语音」页改。

## 五、常见修改

**改回复概率**：面板 →「回复概率」→ 拖动或填写 → 保存全部。立刻生效，不用重启。

**加群**：面板 →「群白名单」→ 填群号 → 添加 → 保存全部。

**改人设**：人设是存在数据库里的。最省事的办法是重跑一次 `安装.bat` 里的那几项 —— 但那只改名字和称呼，不改性格。
要改性格，得直接改数据库的 `personas` 表（`qqbot/AstrBot/data/data_v4.db`），或者用机器人自带的 Web 界面（<http://127.0.0.1:6185> → 人格）。改完要重启。

**换音色**：面板 →「语音」页可以填音色名。音色文件放在 `qqbot/voice-env/src/rvc/assets/weights/`，一个 `.pth` 配一个 `.index`，两个都要在。

**关掉翻唱/开口**：面板 →「附加功能」→ 翻唱 → 关掉 `enabled`。

**改时段降频**：「梁文峰时间」这个插件会在工作时段把主动回复概率砍一半（避开模型接口的高峰价）。面板 →「附加功能」→ 节奏。

## 六、更新

有新版本时，你会拿到一个 `更新包_vX.X.zip`。

1. 把它放到安装目录里（和 `安装.bat` 同一层）。
2. 双击 `更新.bat`。
3. 它会告诉你新版号，然后只替换程序文件。

**你的东西一样都不会动**：API Key、群白名单、聊天记录、人设、心情、记住的事、唱过的歌、QQ 登录状态，全部保留。各插件的设置也只补新键，不会把你改过的值冲掉。

改之前的文件会备份到 `_更新备份\<时间戳>\`，出问题可以照原样拷回去。

更新包只有几 MB，不含运行时和语音模型 —— 那些只在第一次装的时候下。

## 七、出问题了

| 现象 | 怎么办 |
| --- | --- |
| 双击 `安装.bat` 说端口被占用 | 有别的程序占了 6185 / 6199 / 6099 / 17890。关掉占用的程序再装 |
| 启动后浏览器打不开 6185 | 机器人没起来。看它那个黑窗口里有没有报错，通常是配置文件写坏了，重跑 `安装.bat` |
| NapCat 一直 QR 过期 | 网不好。把 NapCat 窗口关掉，重新双击 `启动机器人.bat` |
| 每次都要扫码 | 登录态没存住。检查 `qqbot/napcat/config/webui.json` 里 `autoLoginAccount` 是不是空着 —— 空着就每次都要扫 |
| 提示登录失败 | NapCat 要求 QQ 是它自己拉起来的。先把电脑上的 QQ 完全退出（任务管理器里确认），再启动 |
| 机器人不回话 | ① 群在不在白名单里 ② 有没有配模型 ③ 面板「心情」页能不能读到数据 ④ 看黑窗口里的报错 |
| 答非所问、接错话题 | 上下文太长或人设被改坏了。面板 →「token 与模型」→ 把「上下文保留轮数」调小一点试试 |
| 翻唱一直转圈 | 没显卡的话一首歌确实要几分钟。超过 15 分钟没反应，去面板「语音」页看运行时齐不齐 |
| 说话没声音 | 面板「语音」页会写清楚缺什么。多半是语音包没装或者音色文件没了 |
| 面板打不开、没反应 | 看安装目录下有没有 `面板错误.log` —— 里面是完整的报错 |

**新号容易被风控。** QQ 登录成功后建议先挂一晚上，别急着拉群。拉进群以后第一两天少让她主动说话。

## 八、目录里都是什么

```
鲸鲸bot\
├─ 安装.bat              安装向导
├─ 更新.bat              换新版本
├─ 启动机器人.bat        启动（每次开机后双击一次）
├─ 启动面板.bat          打开设置窗口
├─ 面板.py               面板本体
├─ 使用说明.md           就是这份
├─ 安装记录.json         你填过的东西，重装时带出来当默认值
├─ _面板备份\            面板改配置前的备份
├─ _更新备份\            更新前的备份
├─ tools\                安装和更新的脚本
├─ runtime\python\       机器人用的 Python（不要动）
└─ qqbot\
   ├─ AstrBot\           机器人本体
   │  └─ data\
   │     ├─ cmd_config.json   接口地址、Key、群白名单都在这
   │     ├─ data_v4.db        聊天记录、人设、token 统计
   │     └─ plugins\          各个小插件和它们的数据
   ├─ napcat\            QQ 协议端（登录状态在这里）
   └─ voice-env\         翻唱和语音用的环境 + 音色模型
```

**想彻底重来**：把整个文件夹删掉重装。想保留数据重来：只删 `qqbot/AstrBot/data/data_v4.db` 之外的东西太麻烦，不如直接备份 `data` 文件夹。
